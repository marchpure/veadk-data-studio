# Support

## Community Support

Use GitHub Issues for:

- Reproducible bugs.
- Broken setup or install paths.
- Security hardening work that is not sensitive.
- Documentation gaps.
- Feature requests with a clear use case.

Use GitHub Discussions for:

- Setup questions.
- Ideas and design discussion.
- Connector usage questions.
- Sharing examples and workflows.

Do not include secrets, database credentials, API keys, private schemas, or sensitive query results in public issues or discussions.

## Security Reports

Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Community vs Teams

The community version is intended for local-first individual and OSS usage. Byaan for Teams adds multi-user and organization-oriented features such as authentication, invitations, RBAC, OAuth, Slack integration, and shared dashboards.

See [docs/licensing.md](docs/licensing.md) for the licensing split.

## What Makes A Useful Bug Report

Include:

- Byaan version or commit SHA.
- Deployment mode.
- Operating system.
- Database type.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Relevant logs with secrets removed.

For MCP issues, include the client name and configuration shape, with tokens and local paths redacted as needed.
